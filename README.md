🐧 Pocket Linux Desktop

Turning an Android smartphone into a Linux desktop computer.

Pocket Linux Desktop is a personal project focused on running a Debian Linux desktop environment on an Android smartphone without root access or removing the existing Android operating system.

The goal is to transform a smartphone into a portable Linux workstation with a graphical desktop, Linux applications, terminal access and development tools.

🎯 Project Objectives

- [x] Install Termux.
- [x] Set up Debian Linux (ARM64).
- [x] Install XFCE desktop environment.
- [x] Install and configure TigerVNC.
- [x] Connect to the desktop using AVNC.
- [ ] Improve desktop stability and background operation.
- [ ] Fix graphical rendering issues.
- [ ] Configure automatic desktop startup.
- [ ] Install essential Linux applications.
- [ ] Set up programming and development tools.
- [ ] Customise the desktop environment.

🛠️ Technologies Used

Technology| Purpose
Android 16| Host operating system
Termux| Linux terminal environment
Debian| Linux distribution
XFCE 4.20| Graphical desktop environment
TigerVNC| Remote desktop server
AVNC| Android VNC client

📱 Hardware

- Device: Redmi 15C
- RAM: 8 GB
- Storage: 256 GB
- Architecture: ARM64

🖥️ Project Vision

The long-term vision is to create a portable Linux workstation capable of supporting:

- Software development
- Linux command-line operations
- Git and GitHub workflows
- Python and JavaScript programming
- File management
- Linux application installation
- Basic cybersecurity learning in safe, authorised environments

📈 Current Progress

The Debian environment and XFCE graphical desktop have been installed successfully. TigerVNC is running, and AVNC has successfully connected to the Linux desktop.

Some graphical rendering and background-session improvements are still in progress.

This repository documents the development process, configurations, challenges, solutions and lessons learned.
